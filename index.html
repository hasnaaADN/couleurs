🔴 Primaires

Rouge, Bleu, Jaune : impossibles à créer par mélange.

🟠 Secondaires

Orange, Vert, Violet : mélange de deux primaires.

🟡 Tertiaires

6 nuances : une primaire + une secondaire adjacente.

Règles de base du mélange :

  • Rouge + Bleu = Violet
  • Rouge + Jaune = Orange
  • Bleu + Jaune = Vert
  • Toutes les primaires = Brun/Gris

Applications

La Saturation

La saturation détermine la pureté d'une couleur : très saturée = vive, désaturée = proche du gris.

Saturation : 100%

Couleur avec saturation ajustable

La Luminosité

La luminosité détermine si une couleur est claire ou sombre, du noir (0%) au blanc (100%).

Luminosité : 50%

Couleur avec luminosité ajustable

Applications pratiques :

  • Lisibilité : texte sombre sur fond clair
  • Hiérarchie visuelle : éléments importants plus clairs ou plus sombres
  • Ambiance : sombre = sérieux, clair = léger

La Température des Couleurs

La température sépare les couleurs chaudes (rouge, orange, jaune) des froides (bleu, vert, violet) et influence l'ambiance.

🔥 Couleurs chaudes

Rouge : Passion, Énergie
Orange : Enthousiasme, Créativité
Jaune : Joie, Optimisme

Effets : stimulantes, créent une sensation de proximité et de chaleur.

❄️ Couleurs froides

Bleu : Calme, Confiance
Vert : Nature, Équilibre
Violet : Mystère, Spiritualité

Effets : apaisantes, créent une sensation de distance et de fraîcheur.
